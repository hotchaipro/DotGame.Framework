// APIs that game code (the framework, its platforms, what's built on it, and the games) must not use: reflection, which
// hinders trimming and costs performance, and LINQ, which allocates. Checked by
// Microsoft.CodeAnalysis.BannedApiAnalyzers (DotGame.BuildPolicy.props) as error RS0030.
//
// Reflection for diagnostics (a type name in a trace, an exception message or a crash report)
// goes through a DiagnosticInfo, the one approved place: the framework's own, and one of its own
// in code built on it. Anything else deliberate is suppressed at the use, with a reason:
//
//     #pragma warning disable RS0030 // Builds a game once, not per frame
//     ...
//     #pragma warning restore RS0030
//
// Entries are documentation comment IDs; a method needs one entry per overload. new T() calls
// Activator.CreateInstance<T>() without naming it, so it can't be banned here: pass a factory.
