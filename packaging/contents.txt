# What each of the framework's packages may contain: check.sh fails on any file in a package that no line
# here allows. A library built on the framework lists its packages in a contents.txt of its own.
#
# "[<package id>]" starts a package's lines ("*" in an id matches anything, as in a tool package's
# build machine), and each line after it is a path inside the package. In a path, "*" matches within
# one folder, "**" across folders, and "{a,b}" either. "[*]" lines apply to every package. A new file
# in a package needs a line here, which is the point: nothing reaches nuget.org unlisted. Every package
# also has its readme and notices: the [*] lines, which a library's check uses too.
